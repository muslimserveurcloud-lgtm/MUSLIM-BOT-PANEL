🚀 Comment lancer un bot

  1. Ajoute le code du bot dans bots/nom-du-bot/.
  2. Ajoute le bot dans panel/bots.json.
  3. Ajoute ses tokens dans Settings → Secrets and variables → Actions.
  4. Va dans Actions → MUSLIM BOT RUNNER → Run workflow.
  5. Choisis l'identifiant du bot et lance le workflow.
